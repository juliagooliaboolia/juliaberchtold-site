# juliaberchtold.com

Astro site. `npm install`, then `npm run dev` to work locally, `npm run build` to build.

- Photos live in `public/img/`; which photo goes where is in `src/data/photos.js`.
- Links, email and Instagram are in `src/data/site.js`.
- Pushing to `main` deploys to GitHub Pages (`.github/workflows/deploy.yml`).
- Custom domain: add `public/CNAME` containing `juliaberchtold.com`.
